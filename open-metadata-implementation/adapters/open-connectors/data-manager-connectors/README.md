# The data manager connectors

The data manager connectors work with data management platforms that
use metadata to describe and control access to data.

* [Db2 for Linux, UNIX and Windows (LUW) Server Connectors](db2luw-server-connectors) provides connectors to
  catalog and survey a Db2 LUW server and its databases.
* [DuckDB Connectors](duckdb-connectors) provides connectors to catalog and survey a DuckDB database.
* [Microsoft SQL Server Connectors](mssql-server-connectors) provides connectors to catalog and survey a
  Microsoft SQL Server and its databases.
* [Oracle Server Connectors](oracle-server-connectors) provides connectors to catalog and survey an Oracle
  Database Server and its pluggable databases.
* [PostgreSQL Server Connectors](postgres-server-connectors) provides connectors to catalog and survey a
  PostgreSQL server and its databases.
* [Unity Catalog (UC)](unity-catalog-connectors) provides specialist connectors for working with Unity Catalog.
