# Server Operations client

This module supports `ServerOperationsClient`, the client for issuing queries about, and control operations
against, an [OMAG Server](https://egeria-project.org/concepts/omag-server).  It provides calls to:

* retrieve a server's status, active status and active configuration;
* list the services currently active in a server; and
* load an [open metadata archive](https://egeria-project.org/concepts/open-metadata-archive) into a running
  server, from a file, a connection, or its content supplied directly.
