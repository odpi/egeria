# Server Operations with Spring

The server operations with Spring module uses Spring to implement a REST API wrapper for the
[server-operations-server](../server-operations-server) module.

`OMAGServerResource` provides the REST API for controlling the start-up, management and shutdown of services
in the OMAG Server.
