# Multi Language OMVS 

The Multi Language OMVS enables the caller to define and manage translations of open metadata content, so that
the same metadata elements can be presented in different natural languages.

Link to documentation: [https://egeria-project.org/services/omvs/multi-language/overview/](https://egeria-project.org/services/omvs/multi-language/overview/)

Sample REST API requests can be found in [Egeria-api-multi-language.http](Egeria-api-multi-language.http).
