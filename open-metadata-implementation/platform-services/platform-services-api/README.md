# Platform Services API

The platform services API module provides the property and REST response structures used to query the
[OMAG Server Platform](https://egeria-project.org/concepts/omag-server-platform).

* `BuildProperties` describes the build information for the platform.
* `PublicProperties` provides the name, description and organization for the platform, as configured in the
  platform's `application.properties` file.
* `ServerListResponse` returns the list of servers running on the platform.
