# Platform Services with Spring

The platform services with Spring module uses Spring to implement a REST API wrapper for the
[platform-services-server](../platform-services-server) module.

* `OMAGServerOperationResource` wraps `OMAGServerPlatformOperationalServices`.
* `OMAGServerPlatformActiveResource` wraps `OMAGServerPlatformActiveServices`.
* `OMAGServerPlatformOriginResource` wraps `OMAGServerPlatformOriginServices`.
* `OMAGServerPlatformSecurityResource` wraps `OMAGServerPlatformSecurityServices`.
