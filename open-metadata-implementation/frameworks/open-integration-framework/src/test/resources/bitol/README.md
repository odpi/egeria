# Bitol example documents

The files in `odcs` and `odps` are the example documents published by the Bitol project
(Apache-2.0 licensed) and are used to verify that Egeria's beans can read and write every construct
that the standards exercise.

* `odcs/*.odcs.yaml` from https://github.com/bitol-io/open-data-contract-standard/tree/main/docs/examples
* `odps/*.odps.yaml` from https://github.com/bitol-io/open-data-product-standard/tree/main/docs/examples

They are copied unchanged.  Refresh them when moving to a new release of either standard.
