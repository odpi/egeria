# Distribution Hub

The *distribution-hub* directory (or any of its subdirectories) is where the Egeria runtime writes files that are
intended for people and other tools to pick up, such as the documents written by the Bitol File Store integration
connector (in `bitol`).  It is the outbound counterpart of the *loading-bay*.  You may choose to share this directory
with other tools, or use it as a mount point for external storage.
