# Additional runtime files and utilities

This directory contains additional files and client programs that may be useful when running Egeria.

* `logback.xml` is a sample logging configuration.  Copy it into the `platform/extra` directory to
  turn on debug logging - see the `platform/logs` directory for more information.
* The `reports` directory contains client programs that report on aspects of a running Egeria deployment.
